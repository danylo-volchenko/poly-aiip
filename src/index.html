        Workflow

        1. Generate dataset — sequences per formula (4): Tmax = random(min…max), Tmin = Tmax − random(tol), each of K values picks Tmax or Tmin. Stratified 80/20 train/test split.
        2. Train model — threshold sweep: each epoch scans a 5×5 grid of (low, high) BPM boundaries, keeps the best, shrinks the search box. Error = 1 − best accuracy. Brain.js replaces this engine in lab 2 behind the same interface.
        3. Recognize rhythm — any sequence ≥ K values, sliding window of K with step 1, probabilities averaged over windows. Values convert between BPM and RR (ms) via 60000 / RR.

        Class ranges, BPM

        • Normal: 60–100
        • Tachycardia: 100–140
        • Bradycardia: 40–60

        Limits

        • Sequence length for recognition: K to 200 values
        • BPM accepted: 20–300; RR accepted: 200–3000 ms
        • File loads: dataset .csv/.json, sequence .txt/.csv, model .json
        • Engine: threshold heuristic (Brain.js integration lands in lab 2)
