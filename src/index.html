        Help

        Workflow

        1. Generate dataset - sequences per formula (4): Tmax = random(min…max), Tmin = Tmax − random(tol), each of K values picks Tmax or Tmin. Stratified 80/20 train/test split.
        2. Train model - a Brain.js feed-forward network (K inputs, one hidden layer, 3 outputs) is trained inside a Web Worker, one epoch per iteration. Learning rate, momentum and hidden neurons configure the network; early stop halts when the training error drops below the threshold. If the Worker cannot start, training falls back to the main thread.
        3. Recognize rhythm - any sequence ≥ K values, sliding window of K with step 1, probabilities averaged over windows. Values convert between BPM and RR (ms) via 60000 / RR.
        4. Benchmark - runs timing scenarios for inference vs sequence length, evaluation and training vs dataset size, window K and training epochs. Each case discards a warm-up run and reports min, mean and median over the configured repeats; results export as CSV or JSON.

        Class ranges, BPM

        • Normal: 60–100
        • Tachycardia: 100–140
        • Bradycardia: 40–60

        Limits

        • Sequence length for recognition: K to 200 values
        • BPM accepted: 20–300; RR accepted: 200–3000 ms
        • File loads: dataset .csv/.json, sequence .txt/.csv, model .json
        • Benchmark: sequence lengths, dataset sizes, K, epochs and repeats are configurable; a full browser battery can take several minutes
        • Benchmark: canonical report numbers come from the Node runner node bench/run.js; the in-app panel is a demo and may differ in absolute times
        • Engine: Brain.js 2.0.0-beta.24 feed-forward neural network (trained in a Web Worker, main-thread fallback)
